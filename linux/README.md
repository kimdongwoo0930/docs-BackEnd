## 📌 학습 순서 추천

```
자주 쓰는 명령어 (실습 기반으로 감 잡기)
    ↓
파일 시스템 구조 (왜 /etc, /var, /usr인지 이해)
    ↓
권한 & 사용자 관리 (보안의 기초)
    ↓
프로세스 관리 (백엔드 서버 운영 필수)
    ↓
Shell 스크립트 (반복 작업 자동화)
    ↓
네트워크 명령어 (서버 트러블슈팅)
```
